# Аудиомодем HEX — хакатон

Передача файлов звуком между двумя устройствами (колонки -> микрофон)
с гибридной адаптацией под шум канала.

## Состав

- [`app/modem.py`](app/modem.py) — консольное демо-приложение (меню, TX/RX,
  сессионный протокол: handshake -> ARQ stop-and-wait -> пробник SNR ->
  fallback-деградация режимов 64QAM/16QAM/QPSK/FSK -> EOF + MD5).
- [`app/README.md`](app/README.md) — подробная документация: протокол,
  откалиброванные пороги режимов, 3 уровня адаптации, сценарии видео-тестов.
- [`labs/`](labs/) — 7 Jupyter-ноутбуков лабораторных (сигналы, канал, FSK,
  FEC, OFDM, ARQ, финальное сравнение) и DSP-библиотека
  [`labs/common/modem_lib.py`](labs/common/modem_lib.py).

## Запуск

```
python app/modem.py
```

При первом запуске недостающие зависимости (`numpy`, `scipy`,
`sounddevice`, `reedsolo`) докачиваются автоматически. Либо вручную:

```
pip install -r app/requirements.txt
```

- На принимающем устройстве: пункт **2) Принять файл**.
- На передающем: **6) Проверка связи** (пинг), затем **1) Передать файл**.
- Без железа: **5) Loopback-тест** — весь стек в цифровом канале с заданным SNR.

Файлы для передачи кладутся в `app/files_to_send/` (в меню выбираются номером),
принятые появляются в `app/received/`.
